# 🏠 Hostel Bot — Telegram-бот для бронирования хостела

Telegram-бот для автоматизации бронирования хостела в Казани. Гости бронируют номера 24/7 без участия человека. Админы управляют бронью, отзывами и получают уведомления в Telegram.

---

## 🚀 Возможности

### Для гостей
- 🏠 Информация о хостеле, номера и цены
- 📅 Бронирование номеров с интерактивным календарём
- ❌ Отмена брони (не позднее чем за 24 часа до заезда)
- ⭐ Отзывы — просмотр и написание
- 📞 Связь с администратором
- 📍 Карта и схема проезда

### Для администраторов (`/admin`)
- 📋 Просмотр всех броней по статусам
- ✅ Подтверждение брони (гость получает уведомление)
- 🚫 Закрытие дат (техническая блокировка номеров)
- 📊 Статистика загрузки и выручки
- ⭐ Модерация отзывов
- 📢 Рассылка сообщений всем гостям

### Автоматизация
- 🔔 Напоминания гостям за день до заезда
- 📧 Уведомления админам о новых бронях
- 📊 Экспорт в Google Таблицы
